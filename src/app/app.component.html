PROFESSIONAL PROFILE

Software engineering meets language access.

ZBNIAMEY
EST. IN CODE

I'm a full-stack software developer based in Niamey, Niger, with a growing focus on applied AI and language technology.

My software work spans backend services, APIs, data modelling and frontend applications. Alongside this, I explore how existing AI models can be adapted to support languages with limited digital resources.

My current language-technology work focuses on Zarma speech synthesis and machine translation. These projects involve practical challenges such as corpus preparation, model adaptation and evaluating outputs carefully rather than assuming that a model is reliable by default.

I’m interested in building technology that is useful, maintainable and relevant to the communities it serves.
