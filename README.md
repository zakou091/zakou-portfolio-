# Zakou Birma — Portfolio (Angular)

A light, minimal, responsive portfolio starter built with Angular standalone components.

## Requirements

- Node.js LTS compatible with Angular 19
- npm

## Run locally

```bash
npm install
npm start
```

Open the local URL printed by Angular CLI (usually `http://localhost:4200`).

## Production build

```bash
npm run build
```

The build output is written to `dist/zakou-portfolio/browser`.

## Main files

- `src/app/app.component.ts`: project data, skills, navigation state and page component
- `src/app/app.component.html`: page structure and content
- `src/app/app.component.css`: component layout and responsive design
- `src/styles.css`: global styles
- `src/index.html`: page title, description, fonts and language metadata

## Before publishing

1. Replace the CSS-generated hero illustration with your own portrait or brand visual if desired.
2. Add real repository/demo links only when you have verified public URLs. The current project cards intentionally do not claim to have public demos.
3. Review every technology and project description to ensure it accurately reflects your current experience.
4. Add a downloadable CV only after placing the correct file in the public assets folder and linking to it.
5. Update social links and email if they change.
6. Consider adding a French version and a privacy-friendly analytics solution if needed.

## Notes

The current project illustrations are created with CSS and HTML, so no image assets are required. Google Fonts are loaded from an external service; replace them with local fonts if you prefer a fully self-hosted site.
